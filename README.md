# 园区装卸位预约与放行系统

- 行业：物流（园区调度）
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务闭环

预约（车牌 / 温区 / 装卸位 / 时段）→ 超时未入场自动释放 → 入场锁定 → 装卸完成录入铅封号、净重、备注 → 缺项不得放行 → 放行留痕；改约先释放原位再建新约；装卸中取消须填原因并生成新预约。

## 规则（领域层 `src/domain/validation.ts`）

| 编码 | 规则 |
| --- | --- |
| R1 | 车牌、温区、装卸位、时段必填 |
| R2 | 时段开始必须早于结束 |
| R3 | 冷链车（冷藏/冷冻温区）只能使用冷藏位 |
| R4 | 同一装卸位时段不得重叠（半开区间，首尾相接允许） |
| R5 | 入场后预约锁定，不可改泊位/时段 |
| R6 | 铅封号、净重缺项不得放行 |
| R7 | 装卸中取消必须填写原因并生成新预约 |

冲突统一列出：车牌、装卸位、时段、命中规则（R1~R7）及冲突对方信息。

## 分层

- `src/domain/`：领域模型、常量目录、时间工具、纯函数规则引擎（不依赖 Vue / 存储）
- `src/services/storage.ts`：localStorage 版本化读写与状态修复
- `src/stores/yard.ts`：Pinia 应用服务，编排闭环操作与流转流水
- `src/components/`、`src/App.vue`：展示层（表单、看板、列表、历史、冲突提示）

预约、泊位占用与放行历史保存在同一份状态（`dfwlfront-3-yard-reservation-v1`），刷新后三者保持一致；超时释放每 30 秒扫描并在加载时补扫（宽限 15 分钟）。
