# 园区装卸位预约与放行闭环

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、localStorage
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务闭环

1. **预约**：录入车牌、温区（冷冻/冷藏/常温）、装卸位、时段与备注。
2. **规则校验**：
   - 必填项缺失不通过；时段结束必须晚于开始、不能预约过去时间；
   - 冷链车（冷藏/冷冻温区）只能预约冷藏位；
   - 同一装卸位时段半开区间重叠即冲突，冲突清单列出车牌、装卸位、时段和命中规则。
3. **超时释放**：待入场预约超过开始时间 30 分钟仍未入场，系统自动置为「超时释放」并记入历史（每 30 秒轮询，刷新也会触发）。
4. **入场锁定**：入场后状态变为已入场，禁止改约 / 删除，随后进入装卸中。
5. **放行**：装卸完成必须录入铅封号、净重（正数）、放行备注，缺项不得放行。
6. **改约**：待入场状态可改约，先释放原装卸位（旧预约置取消并双向关联），再按全部规则生成新预约。
7. **装卸中终止**：必须填写原因，原预约取消并在同一装卸位按新时段生成待入场新预约。
8. **一致性**：预约、装卸位占用、放行 / 操作历史整体持久化到 localStorage，刷新后完全一致。

## 代码分层

| 目录 | 职责 |
| --- | --- |
| `src/domain/` | 领域模型（`types.ts`）、规则校验（`rules.ts`）、时间工具（`time.ts`），纯函数、无 UI 依赖 |
| `src/services/` | localStorage 快照读写（`storage.ts`）、演示数据（`seed.ts`） |
| `src/stores/` | Pinia 编排层（`dockStore.ts`），所有状态变更与事件记录在此原子完成并持久化 |
| `src/components/` | 页面组件：预约表单、装卸位看板、预约卡片、放行 / 改约 / 终止弹窗、冲突清单、历史时间线 |
